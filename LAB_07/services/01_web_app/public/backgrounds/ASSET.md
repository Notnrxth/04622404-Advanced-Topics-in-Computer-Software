# Matchnight background

This records the earlier neutral background experiment, retained as an unused asset. The active UI now uses five separate `{team-key}.png` stadium images. See `../../CLUB_EDITION.md` from the service root documentation for the current implementation.

The file `matchnight.png` is a decorative stadium image (1536 × 1024), not a photograph of a specific club ground.

Previously used by the home hero, Login artwork and companion card with club color tinting. Replaced by individual club artwork. The image is decorative and contains no interface text.
