# RAG-Project-Thai Fruit Guide (คู่มือผลไม้ไทย)

Build a simple RAG retrieval pipeline from scratch using Python, including Q&A data loading, chunking, embeddings, a vector database, and semantic document search over a Thai fruit knowledge base.

----

# Summary

A simple RAG project for learning the basics, using a Thai fruit guide as the knowledge base. It covers 15 Thai fruits — durian, mangosteen, mango, rambutan, longan, lychee, pomelo, coconut, banana and pineapple in the main document, plus dragon fruit, longkong, rose apple, guava and papaya in the add-document set. Each fruit is described with the same eight topics: name in Thai and English, season, growing regions, taste, appearance, nutrition, buying tips, and trivia. It includes step-by-step code for data loading, text chunking, embeddings, vector database creation, and document retrieval. This project focuses on understanding the RAG workflow and will continue to be improved with more features.
